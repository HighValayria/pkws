# P0 手工验收清单

自动化测试只使用临时模拟文档库。以下桌面交互需在目标 Windows 环境确认；完成前阶段状态保持“实现完成、待人工验收”。

## 右缘入口与窗口

- 普通启动后不出现托盘图标或大窗口；屏幕右缘中部只有一条窄感应条。
- 鼠标贴到感应条后出现向左按钮；移开约半秒后按钮收回。
- 点击按钮后，连续笔记面板出现在当前鼠标所在屏幕右侧，输入框获得焦点；感应条暂时消失。
- 点击右上角箭头或按 `Esc` 后面板收起，右缘入口恢复。
- 再次运行 `PKWS.exe` 应唤起已有实例，不启动第二个常驻进程。
- 在 100%/125%/150% DPI、多显示器、不同任务栏位置及全屏应用上检查位置、误触和遮挡。
- 确认程序不会改变输入法、OneNote、Clash Verge、系统代理或其他软件的键盘行为。

## 笔记体验

- 页面应像一张连续当日笔记，不出现“已有内容（只读）/新增内容”、Vault、时区、路径模板或 API 配置表单。
- 每条历史记录和当前输入上方只显示 `HH:00`；正文支持中文、Emoji、标题、粗体、斜体、列表、引用、代码围栏和链接文本。
- 分别验证 Markdown 工具栏、`Ctrl+B`、`Ctrl+I` 和“预览”；保存后历史块应按 Markdown 排版，原始 `.md` 仍保留语法字符。
- 当历史记录超过一屏时，在历史正文、Markdown 输入框、工具栏和预览区上方分别滚动鼠标滚轮；整张笔记应连续上下移动，不得只移动一小段后失效。
- 用中文输入法输入、候选、换行、粘贴和撤销；`Ctrl+Enter` 与右下角按钮都能保存。
- 保存后该段进入上方连续记录，草稿清空，界面只显示“已保存”。
- 输入未保存草稿后收起、退出并重启，确认草稿恢复；跨午夜时确认出现简短日期提示。

## 文件与可靠性

- 确认程序目录自动出现 `doc\Daily\YYYY\YYYY-MM-DD.md`，设置中显示同一路径且可打开文件夹。
- 检查 Markdown 正文原样可读，可见标题按小时显示；隐藏注释包含稳定记录边界。
- 连续双击保存、重复启动、睡眠/唤醒后保存，不应产生重复记录。
- 用外部编辑器修改每日文件后再追加，人工修改不得被覆盖；文件占用或目录不可写时不得谎报成功。
- 通过设置中的“退出 PKWS”结束进程；收起面板只隐藏，不退出。
